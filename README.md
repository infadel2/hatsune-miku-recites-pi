## instructions
install at least Python 3.13.2 and open `main.py` in a text editor. change `data/pi.txt` to any file in the `data` folder (or even your own if you're into that) and then just double click `main.py`. you should get an `output.txt` where you can just paste it to the end of a blank .osu file

do note that output.txt does not clear automatically when running (i cant be asked im sorry). if you run this multiple times, make sure to delete the previous output.txt or else you'll end up having two different maps at the same time
